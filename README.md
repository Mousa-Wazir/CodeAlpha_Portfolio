# CodeAlpha_Portfolio — Mousa Wazir

**Frontend Development Internship — Task 3: Personal Portfolio Site**

## Overview
Personal developer portfolio website for **Mousa Wazir** (Software Engineering Graduate • Frontend Developer • Aspiring Master's Scholar), built with semantic **HTML5, CSS3, and Vanilla JavaScript**.

## Features
- **Complete CV Integration**: Showcases Executive Profile, Technical Skills, Key Projects (*Localena FYP*, *CodeAlpha Calculator*, *CodeAlpha Image Gallery*), Professional Experience (*DevBazm*, *LMAR Marketing*, *Afridi Trading Japan*), Education (*CECOS University*, *SMIT*), and Certifications (*Cisco*, *DigiSkills*, *MCI Peshawar*).
- **Downloadable Resume**: Includes `Mousa_Wazir_CV.pdf` wired to the Download CV button.
- **Smooth Scroll & Scroll-Reveal Animations**: Built with native CSS `scroll-behavior: smooth` and JavaScript `IntersectionObserver`.
- **Responsive Design**: Adapts across mobile, tablet, and desktop viewports.

## Deployment (Bonus)
Enable **GitHub Pages** in repository `Settings -> Pages -> Branch: main` to publish live.
